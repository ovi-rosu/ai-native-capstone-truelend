## User Story
As an admin, I want the portfolio broken down by product and delinquency bucket with a total overdue figure so that I can see the book's health at a glance.

## Business Value
Turns loan-level delinquency state into the portfolio view the business actually manages against.

## Description
The FR-15 dashboard. Per D11 it is a read model over the loan bucket state and overdue installments E11-S2 maintains, with no dependency on the end-of-day job. The total overdue figure must reconcile to the sum of overdue installment amounts across active loans.

## Scope
**In:** Per-product, per-bucket loan count and value aggregation; Total overdue figure reconciling to overdue installment amounts; Admin-only dashboard surface
**Out:** must not trigger or depend on the end-of-day job, per D11; must not report a fee, penalty or collections figure; must not be reachable with a CUSTOMER session

## Acceptance Criteria
- **E14-S1-AC1** — *Given* loans spread across products and delinquency buckets, *when* an admin opens the dashboard, *then* the loan count and value are reported for every product and bucket combination.
- **E14-S1-AC2** — *Given* those same loans, *when* the total overdue figure is read, *then* it equals the sum of overdue installment amounts across all active loans.
- **E14-S1-AC3** — *Given* a CUSTOMER session, *when* the dashboard endpoint is called with it, *then* the response is 403 and no portfolio figures are returned.
- **E14-S1-AC4** — *Given* the dashboard request, *when* its data source is traced, *then* the figures are served from stored loan bucket state without invoking the end-of-day job.

### Operations
1. Define the `PortfolioSummary` value object (by-product, by-bucket loan count and value, and `total_overdue`) and `PortfolioRepository.summary() -> PortfolioSummary` in `backend/src/repository/delinquency/portfolio_repository.py` (new): aggregate loan count and value per `product_code` and `delinquency_bucket` from the stored `loan.outstanding_principal` and `loan.delinquency_bucket` projections (maintained by E11-S2), and sum the overdue installment amounts across active loans for `total_overdue` — a read-only query, with no write and no call to the end-of-day run.
2. Define `portfolio_summary() -> PortfolioSummary` in `backend/src/service/delinquency/portfolio.py` (new): delegate to `PortfolioRepository.summary()` only; this is the single call path and it never invokes `delinquency.run_end_of_day` (owned by E12-S1), per D11.
