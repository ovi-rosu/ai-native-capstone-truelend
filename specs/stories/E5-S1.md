## User Story
As an underwriter, I want a deterministic credit score from the applicant's age, income and credit-history flags so that two identical applications are never judged differently.

## Business Value
Makes every decision reproducible and disputable on the record, without a live bureau dependency.

## Description
Deepens the tracer's shallow score into the real FR-03 stub: a pure function over age, income and credit-history flags that returns the identical score for identical input and a different score when only the credit-history flags change. No external bureau is called, per SG-2.

## Scope
**In:** Scoring function over age, income and credit-history flags; Determinism and flag-sensitivity tests; Score persisted against the application
**Out:** must not call an external credit bureau or any live provider; must not introduce randomness, wall-clock time or request order into the score; must not read a threshold from anywhere but the application's pinned policy version

## Acceptance Criteria
- **E5-S1-AC1** — *Given* one set of age, income and credit-history-flag values, *when* the scoring stub is called repeatedly with it, *then* every call returns the identical score.
- **E5-S1-AC2** — *Given* two inputs differing only in their credit-history flags, *when* both are scored, *then* the two returned scores differ.
- **E5-S1-AC3** — *Given* the scoring stub under test, *when* its outbound collaborators are inspected, *then* no external credit-bureau call and no live provider credential is used.
